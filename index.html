Understanding the mathematics behind neural networks, differential equations, and PINNs.

Start here: the big idea

No mathematics is needed for this part. Three questions, one picture.

What is a differential equation?
A rule that says how something changes: how heat spreads, how a fluid flows, how a hanging cable bends. To solve it means to find the curve (or surface) that obeys the rule.
What is a neural network?
A very flexible curve with many knobs. The knobs are numbers called weights; turn them and the shape of the curve changes.
What is a physics-informed neural network (PINN)?
Turn the knobs until the curve obeys the rule. The rule itself is the teacher, so for a forward problem no measured solution is needed, only the rule and the conditions at the boundary.

Think of bending a flexible wire so that it passes through two fixed pins and also bends the way the rule demands. Check where it disobeys, bend it a little, check again. Watch exactly this happen below; it is a real run of a small PINN in your browser.

The idea in four steps

A PINN is a flexible curve that is trained, step by step, to break the rule less and less.

1. Introduction

Physics-informed neural networks (PINNs) use a feedforward neural network to approximate the solution of a differential equation. To see why this works, three ingredients are needed, in this order:

  1. Feedforward neural networks: a neural network is a composite function.
  2. Differential equations: the Bratu equation (ODE) and the Burgers equation (PDE), and how they are solved classically.
  3. Physics-informed neural networks: the network is trained so that it satisfies the equation, followed by forward and inverse problems.

Each part follows the same pattern: concept, formulation, an interactive example, and a short takeaway. Change the parameters in the control panels and the graphs update immediately.

2. Feedforward Neural Networks

2.1 Composite function

A composite function is a function formed by applying one function to the output of another function. For \(f(x)=x^2\) and \(g(x)=x+1\), the composite function is

$$y = f\circ g(x) = f(g(x)) = (x+1)^2 .$$

More compositions chain the same idea:

$$x \;\to\; f_1(x) \;\to\; f_2\big(f_1(x)\big) \;\to\; f_3\Big(f_2\big(f_1(x)\big)\Big)$$
Interactive composite function

A network is built the same way: the output of one operation becomes the input of the next.

2.2 Feedforward neural network

A feedforward neural network is a composite function of multiple variables, consisting of many linear and nonlinear functions. For example, \(y = f(w_1x_1+w_2x_2+b_1)\) makes \(y\) a function of \(x_1\) and \(x_2\), and

$$y = f\Big(w_5\, f(w_1x_1+w_2x_2+b_1) + w_6\, f(w_3x_1+w_4x_2+b_2) + b_3\Big),$$

where \(f\) is a nonlinear activation function, such as \(\tanh\) or ReLU. Here \(w\) is a weight and \(b\) is a bias; sometimes all of them are called weights or trainable parameters. A feedforward neural network is also called a multilayer perceptron or a fully connected network.

2.3 Layer-wise computation

Instead of computing the whole expression at once, write it layer by layer:

$$h_1 = f(w_1x_1+w_2x_2+b_1),\qquad h_2 = f(w_3x_1+w_4x_2+b_2),\qquad y = f(w_5h_1+w_6h_2+b_3).$$

This is a neural network with one hidden layer containing two neurons (nodes). Edit any value below; the diagram and every step of the computation are recomputed.

Neural network and layer-wise calculator

Each neuron computes a weighted sum of its inputs, adds a bias, and applies the activation function.

2.4 Matrix representation

Matrix and vector computations are faster, so the same network is written with matrices. In column form,

$$H_1=\begin{bmatrix}h_1\\ h_2\end{bmatrix}=f\!\left(\begin{bmatrix}w_1&w_2\\ w_3&w_4\end{bmatrix}\begin{bmatrix}x_1\\ x_2\end{bmatrix}+\begin{bmatrix}b_1\\ b_2\end{bmatrix}\right)=f(W_1X+B_1),\qquad y=f\!\left(\begin{bmatrix}w_5&w_6\end{bmatrix}\begin{bmatrix}h_1\\ h_2\end{bmatrix}+b_3\right)=f(W_2H_1+B_2).$$

Or, in row form,

$$H_1=\begin{bmatrix}h_1&h_2\end{bmatrix}=f\!\left(\begin{bmatrix}x_1&x_2\end{bmatrix}\begin{bmatrix}w_1&w_3\\ w_2&w_4\end{bmatrix}+\begin{bmatrix}b_1&b_2\end{bmatrix}\right)=f(XW_1+B_1),\qquad y=f\!\left(\begin{bmatrix}h_1&h_2\end{bmatrix}\begin{bmatrix}w_5\\ w_6\end{bmatrix}+b_3\right)=f(H_1W_2+B_2).$$
Matrix calculator (row form, same values and activation as in section 2.3)

2.5 Adding more hidden layers

A network with 2 inputs, 4 hidden layers of 20 nodes each, and 1 output, with \(X=[x\;\;y]\):

$$H_1=f(XW_1+B_1),\; H_2=f(H_1W_2+B_2),\; H_3=f(H_2W_3+B_3),\; H_4=f(H_3W_4+B_4),\; u=f(H_4W_5+B_5).$$

2.6 Example: function approximation

The basic application of neural networks is function approximation, or regression. Approximate \(u(x)=\sin(4\pi x)\), \(x\in[0,1]\), by a neural network function \(u(x;W)\) found by optimisation. Choose collocation points \(x_i = 0.01\times i\), \(i=0,1,\dots,100\). The unknowns are the weights \(W\), and the loss function is

$$L(W)=\mathrm{MSE},\qquad \mathrm{MSE}=\frac1N\sum_{i=1}^{N}\Big(u(x_i;W)-u_{\mathrm{true}}(x_i)\Big)^2 .$$

A standard optimiser is gradient descent, \(W_{\mathrm{new}}=W_{\mathrm{old}}-\eta\,\nabla L(W)\); a quasi-Newton alternative is the BFGS algorithm. In the slides, BFGS gives a loss of \(3.80874\times10^{-6}\) (MATLAB code).

Approximating A sin(kπx)

The neural network attempts to approximate the target function. The default \(A=1,\ k=4\) is the slides' \(\sin(4\pi x)\) with 101 points. This demo uses one hidden layer of tanh neurons and the Levenberg–Marquardt algorithm. Changing a parameter restarts the training. With very few points the network can match the points but not the function between them.

Training means choosing the weights \(W\) that minimise the mismatch between the network and the target at the collocation points.

3. Differential Equations

3.1 Examples

Ordinary differential equation (ODE). The one-dimensional Bratu equation:

$$u_{xx}+Ce^{u}=0,\quad x\in[0,1],\qquad u(0)=0,\quad u(1)=0.$$

The objective is to approximate the solution \(u(x)\) across the domain.

Partial differential equation (PDE). The Burgers equation, in the form used by Raissi et al. (2019),

$$u_t+u\,u_x-\frac{0.01}{\pi}\,u_{xx}=0 .$$

The objective is to approximate the solution \(u(x,t)\) across the domain.

3.2 Common solvers

Time-independent: \(u(x)\), \(u(x,y)\)Time-dependent: \(u(x,t)\)
  • Finite difference method
  • Finite element method
  • Spectral method

Time integration + spatial derivative/discretisation.

Time integration: Euler method, Runge–Kutta method, ode45 (MATLAB).

Spatial discretisation: finite difference, finite element, or spectral method.

3.3 Finite difference method

Take the Bratu equation with \(C=2\). Its analytical solution is

$$u(x)=-2\ln\!\left(\frac{\cosh\big(\theta(2x-1)\big)}{\cosh\theta}\right),\qquad \theta=\sqrt{C/8}\,\cosh\theta,$$

which for \(C=2\) gives \(\theta\approx 0.589387763469351\).

To find the approximation \(u(x_k)=u_k\): divide \([0,1]\) into \(N=100\) subintervals with \(h=1/N\), take the grid points \(x_k=0.01\times k\), \(k=1,\dots,99\), set \(u_0=0\), \(u_{100}=0\), and let \(u_k\), \(k=1,\dots,99\), be the unknowns. Discretising the equation at each grid point,

$$u_{xx}(x_k)+Ce^{u(x_k)}=0,\qquad k=1,\dots,99,$$

and approximating \(u_{xx}\) with the central finite difference formula,

$$u_{xx}(x_k)\approx\frac{u_{k+1}-2u_k+u_{k-1}}{h^2},$$

gives a system of nonlinear equations

$$\frac{u_{k+1}-2u_k+u_{k-1}}{h^2}+Ce^{u_k}=0,\qquad k=1,\dots,99.$$

The slides solve it with the Levenberg–Marquardt algorithm (MATLAB code). The demos below solve the same system with Newton's method, which is simpler for a tridiagonal Jacobian.

Central difference at one grid point

The three points are drawn with the parabola through them; the finite difference formula equals the (constant) second derivative of that parabola. The presets sample the exact function at the neighbours of \(x_k\) (\(x_k=0.5\) for Bratu, \(x_k=0.1\) for the sine) using the current \(h\), so you can watch the error shrink as \(h\) decreases.

3.4 Interactive Bratu equation

Change \(C\) and the number of subintervals \(N\). The numerical solution is the finite difference solution; the analytical solution is the formula above. Both satisfy \(u(0)=u(1)=0\).

Bratu equation: uxx + C eu = 0

Why is there a largest C?

The condition \(\theta=\sqrt{C/8}\cosh\theta\) has two solutions for small \(C\) (two branches of the Bratu problem), one solution at a critical value \(C^*\approx 3.5138\), and none beyond it. Newton's method started from \(u\equiv 0\) finds the lower branch, which is the one plotted here; for \(C>C^*\) the iteration diverges.

A classical solver needs a grid. The next part replaces the grid and the discretised equations by a neural network.

4. Physics-Informed Neural Networks

4.1 Idea

PINNs use a feedforward neural network to approximate the solution of a differential equation. For the Burgers equation the solution is approximated by a continuous neural network function \(u(x,t;W)\) with, for example, two hidden layers. The unknowns are the weights \(W\). The equation enters through the loss function. Select a stage to read what it does.

4.2 Collocation points

Choose random or grid interior points \((x^{I}_i,t^{I}_i)\), \(i=1,\dots,N_i\), and random or grid boundary/initial points \((x^{B}_i,t^{B}_i)\), \(i=1,\dots,N_b\). The graph shows the domain \(x\in[-1,1]\), \(t\in[0,1]\) used for the Burgers equation by Raissi et al. (2019).

Collocation points

4.3 Loss function

The loss function is \(L(W)=\mathrm{MSE}_i+\mathrm{MSE}_b\). For the Burgers equation, the PDE residual at the interior points is

$$\mathrm{MSE}_i=\frac1{N_i}\sum_{j=1}^{N_i}\Big(u_t+u\,u_x-\tfrac{0.01}{\pi}u_{xx}\Big)^2\Big|_{(x^I_j,\,t^I_j;\,W)},$$

and the boundary/initial residual is

$$\mathrm{MSE}_b=\frac1{N_b}\sum_{j=1}^{N_b}\Big(u(x^B_j,t^B_j;W)-u_{\mathrm{true}}(x^B_j,t^B_j)\Big)^2 .$$

For the Bratu equation, with \(C=2\),

$$\mathrm{MSE}_i=\frac1{N_i}\sum_{j=1}^{N_i}\Big(u_{xx}(x^I_j;W)+2e^{u(x^I_j;W)}\Big)^2,\qquad \mathrm{MSE}_b=\frac1{N_b}\sum_{j=1}^{N_b}\Big(u(x^B_j;W)-0\Big)^2,$$

and the loss can be weighted, \(L(W)=\mathrm{MSE}_i+\alpha\,\mathrm{MSE}_b\), where \(\alpha\) balances the two terms.

4.4 Derivatives and automatic differentiation

  
The loss needs \(u_x\), \(u_{xx}\) and \(u_t\) of the network output. Because the network is a composite function, they follow from the chain rule applied layer by layer; this is automatic differentiation.


u(x,t)
 │
 ├── ∂u/∂x
 │      │
 │      └── ∂²u/∂x²
 │
 └── ∂u/∂t

  
For the first layer \(H_1=f(XW_1+B_1)\) with \(X=[x\;\;t]\) and \(Z_1=XW_1+B_1\), write \(w^{(x)}\) and \(w^{(t)}\) for the rows of \(W_1\) belonging to \(x\) and \(t\):

  $$\frac{\partial H_1}{\partial x}=f'(Z_1)\odot w^{(x)},\qquad
    \frac{\partial H_1}{\partial t}=f'(Z_1)\odot w^{(t)},\qquad
    \frac{\partial^2 H_1}{\partial x^2}=f''(Z_1)\odot\big(w^{(x)}\big)^2 .$$
  
Later layers continue the chain, for example \(\partial H_2/\partial x=f'(Z_2)\odot\big(\partial H_1/\partial x\;W_2\big)\).
     The demo uses a fixed network with one hidden layer, \(u(x)=\sum_j v_j f(a_jx+c_j)+d\) with \(f=\tanh\), so that

  $$u_x=\sum_j v_ja_j\,f'(z_j),\qquad u_{xx}=\sum_j v_ja_j^2\,f''(z_j),\qquad z_j=a_jx+c_j,\quad f''=-2f\,(1-f^2).$$

5. PINNs — Forward Problems

  
In a forward problem the equation and its parameters are known, and the solution is unknown. The slides use the one-dimensional Bratu equation

  $$u_{xx}+Ce^{u}=0,\quad x\in[0,1],\qquad u(0)=0,\ u(1)=0,\qquad C=2 .$$
  
Choose random interior points \(x^I_i\in[0,1]\) with \(N_i=99\), and two boundary points \(x^B_1=0\), \(x^B_2=1\) (\(N_b=2\)). The loss is

  $$L(W)=\mathrm{MSE}_i+\alpha\,\mathrm{MSE}_b,\qquad
    \mathrm{MSE}_i=\frac1{N_i}\sum_{j}\Big(u_{xx}(x^I_j;W)+Ce^{u(x^I_j;W)}\Big)^2,\quad
    \mathrm{MSE}_b=\frac1{N_b}\sum_{j}u(x^B_j;W)^2 ,$$
  
minimised over \(W\) (BFGS in the slides; the slides report a loss of \(2.47038\times10^{-7}\),
     MATLAB code).

6. PINNs — Inverse Problems

  
The one-dimensional Bratu equation with unknown parameters \(\lambda=(\lambda_1,\lambda_2)\):

  $$u_{xx}+\lambda_1e^{\lambda_2u/2}=0,\quad x\in[0,1],\qquad u(0)=0,\ u(1)=0,$$
  
with \(C=1\) and true values \(\lambda_1=1\), \(\lambda_2=2\). Given partial observations of the solution (data) \(\big(x_i,u(x_i)\big)\), \(i=1,\dots,N\),
     and the known structure of the differential equation, the objective is to identify \(\lambda\) while simultaneously approximating the solution \(u\).

  

    
Inverse problem

    

      Observed Data→
      Neural Network→
      u(x)→
      Differential Equation→
      Estimate λ1, λ2
    

  

  
The loss function is \(L(W,\lambda_1,\lambda_2)=\mathrm{MSE}_{DE}+\mathrm{MSE}_{data}\), where

  $$\mathrm{MSE}_{DE}(W,\lambda_1,\lambda_2)=\frac1N\sum_{i=1}^{N}\Big(u_{xx}(x_i;W)+\lambda_1e^{\lambda_2u(x_i;W)/2}\Big)^2,\qquad
    \mathrm{MSE}_{data}(W)=\frac1N\sum_{i=1}^{N}\Big(u(x_i;W)-u_{\mathrm{true}}(x_i)\Big)^2 .$$
  
Equivalently, a least squares problem \(F=[F_{DE};F_{data}]\) with \(F_{DE}=u_{xx}(x_i;W)+\lambda_1e^{\lambda_2u(x_i;W)/2}\) and \(F_{data}=u(x_i;W)-u_{\mathrm{true}}(x_i)\),
     solved by the Levenberg–Marquardt algorithm. The slides report a loss of \(9.1483\times10^{-8}\)
     (MATLAB code).

7. Advantages of PINNs

  
    
    
  • Mesh (or grid)-free
      
    Collocation points can be random; no grid or mesh has to be built (compare the finite difference method in section 3.3).
    • 
    
  • Efficient inverse problems (or parameter estimation)
      
    Equation parameters are simply added to the unknowns of the same loss function (section 6).
    • 
    
  • Automatic differentiation
      
    Derivatives of the network output such as \(u_x\), \(u_{xx}\), \(u_t\) are obtained exactly by the chain rule (section 4.4), without finite difference formulas.
    • 
    
  • Unified framework: ODEs, 2D PDEs, 3D PDEs
      
    The same recipe applies to all of them: network, derivatives, residual, loss. Only the inputs and the residual change.
    • 
    
  • Hard constraint
      
    The initial and boundary conditions can be enforced directly in the network structure instead of through a loss term.
         For example (an illustration, not from the slides), for \(u(0)=u(1)=0\) one can use \(u(x)=x(1-x)\,\mathcal N(x;W)\), which satisfies the boundary conditions for any weights, so \(\mathrm{MSE}_b\) is not needed.
